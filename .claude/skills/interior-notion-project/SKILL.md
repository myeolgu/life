## 관리 규칙
- 내용을 한 페이지에 다시 몰아넣지 말 것. 주제가 하나 늘어나면(예: 시공업체 견적 비교, 참고 이미지 모음) 새 하위 페이지를 만들어 허브에 링크로 추가한다.
- 허브 페이지 내용을 `replace_content`로 바꿀 때는 하위 페이지 링크를 `<page url="...">` 태그로 남겨야 한다. 일반 마크다운 링크(`[text](url)`)로 쓰면 Notion API가 "하위 페이지 삭제" 오류를 낸다.
- 표는 파이프(`|`) 마크다운이 아니라 `<table fit-page-width="true" header-row="true"><tr><td>...</td></tr></table>` 형식을 쓴다. `fit-page-width="true"`를 꼭 넣어야 페이지 폭에 맞게 넓게 렌더링되고, 좁은 열에 텍스트가 줄바꿈되며 답답해 보이는 문제가 없다 (2026-09-06에 사용자가 폭이 좁다고 지적해서 기존 4개 표에 소급 적용함).
- update_content의 old_str/new_str은 실제 저장된 포맷과 정확히 일치해야 하므로, 애매하면 먼저 fetch로 현재 저장 포맷을 확인하고 나서 old_str을 만든다.
- `notion-create-pages`로 허브 페이지를 parent로 지정해 하위 페이지를 만들면, 허브 페이지 콘텐츠 맨 끝에 `<page url="...">` 태그가 자동으로 추가된다. 원하는 위치(하위 페이지 목록 섹션)로 옮기려면 별도 update_content 호출이 필요하다.
- 공사 진행 순서는 착공일 미정 상태라 D1, D2... 상대일로 적어뒀다. 착공일이 확정되면 실제 날짜로 치환할 것.

## 핵심 사실 (틀리기 쉬운 부분)
- 주소는 **인천광역시 부평구 부개동**이다 (부천시 아님 — 처음에 잘못 가정했던 적 있음).
- 아파트 매매 성공일: 2025-12-10. 평형: 25평(전용 약 59㎡).
- 혼인신고: 2026-09-01 서초구청 접수, 혼인관계증명서는 접수 후 10~14일 뒤(약 09-11~15) 발급 예상 — 신혼부부 디딤돌대출 신청은 이 증명서 발급 이후 진행.
- 디딤돌대출 조건(한도/금리/소득기준)은 정책성 정보라 매번 최신 여부를 재검색해서 확인할 것. 이 문서에 적힌 수치를 그대로 신뢰하지 말 것.
